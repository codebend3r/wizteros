# Sidemenu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a login-gated sidemenu listing all six app routes, rendered inside `AdminLayout`.

**Architecture:** A new `SideMenu` component owns the route list and the mobile drawer toggle; `AdminLayout` gains a two-column middle row (sidebar + content). Because every admin page already wraps itself in `AdminGate` → `AdminLayout`, the menu is automatically visible only when logged in.

**Tech Stack:** React 18, react-router-dom 7 (`NavLink`), SCSS modules, vitest + @testing-library/react. Run everything from `web/` with bun.

## Global Constraints

- Named exports only for new code (`export const SideMenu`); never `any`, never type casts; type aliases, not interfaces.
- SCSS modules for component styles; spacing via grid `gap`; all sizes/colors from `styles/globals.scss` tokens; no bare `div`s without a class.
- Prefer `&&` over ternaries whose else branch is null; immutable data; `Array.prototype` methods over loops.
- Commits: subject starts with `WZ:`, bullet body, no AI attribution.
- Spec: `docs/superpowers/specs/2026-07-23-sidemenu-design.md`: routes are Home `/` (with `end`), Members `/manage`, Invite `/invite`, Email `/email`, Reset user `/reset-user`, Member `/user`.

`web/src/components/SideMenu/SideMenu.tsx`:

```tsx
import { useState } from 'react'
import { NavLink } from 'react-router-dom'
import styles from '@/components/SideMenu/SideMenu.module.scss'

export const menuRoutes = [
  { label: 'Home', path: '/' },
  { label: 'Members', path: '/manage' },
  { label: 'Invite', path: '/invite' },
  { label: 'Email', path: '/email' },
  { label: 'Reset user', path: '/reset-user' },
  { label: 'Member', path: '/user' },
] as const

export const SideMenu = () => {
  const [open, setOpen] = useState(false)
  return (
    <aside className={styles.sideMenu}>
      <button
        className={styles.toggle}
        type="button"
        aria-expanded={open}
        onClick={() => setOpen(!open)}
      >
        Menu
      </button>
      <nav
        className={open ? `${styles.menu} ${styles.menuOpen}` : styles.menu}
        aria-label="Sections"
      >
        <ul className={styles.list}>
          {menuRoutes.map(({ label, path }) => (
            <li className={styles.item} key={path}>
              <NavLink
                className={({ isActive }) =>
                  isActive ? `${styles.link} ${styles.linkActive}` : styles.link
                }
                to={path}
                end={path === '/'}
                onClick={() => setOpen(false)}
              >
                {label}
              </NavLink>
            </li>
          ))}
        </ul>
      </nav>
    </aside>
  )
}
```
